# What's changed

To see which version you have, look at the end of any answer: the "Checked on" line names it, for example "Build Advisor 1.1.0". To update, download the skill file again, then in Claude delete the old skill and upload the new one (README, Steps 3 and 4).

## 1.1.0 (October 25, 2026)

- **Ready for launch day.** Information from the beta no longer becomes unusable all at once when the game launches. Only topics that the launch patch notes actually change need new sources.
- **Knows the beta is closed.** Until launch, it stops looking for newer patch notes, and each answer says it is based on the final beta build.
- **Faster answers that use fewer messages.** Single questions get a quick check (about 3 to 5 searches). Full builds and plans still get the full check.
- **Answers first, asks later.** It asks only what it needs before the first answer, then offers to tailor the advice to how you play.
- **Tells you what it is doing.** Before it starts looking things up, it says what it is checking and about how long it takes.
- **Remembers within a chat.** Follow-up questions in the same chat reuse facts it already checked that day.
- **Fewer false disagreements.** "8%", "8 percent", and "8.0%" now count as the same answer.
- **Shows its version** in the "Checked on" line at the end of every answer.

# Trusted sources and how to search them

Every source gets a tier. The fact ledger uses the tier to decide what counts as verified.

## Tier 1: Blizzard (the rulebook)

Blizzard decides the rules: what abilities and talents do, stat conversions, patch changes, item and profession changes, and what is a known issue.

- Blizzard's World of Warcraft news site (worldofwarcraft.blizzard.com), including WoW Forever news, class deep dives, and written recaps of video panels.
- Official patch notes and hotfix notes.
- Blizzard's official forums, only posts from Blizzard staff (blue posts). Development notes and patch note threads that Blizzard's news site links to, or that are posted by a Blizzard community manager, count as staff posts even if the page text does not show a staff badge.
- The in-game text of a spell, talent, or item as shown on a Tier 2 database site counts as Tier 1 only if the page says it is from the live or current beta game version. Otherwise treat it as Tier 2.

A single current Tier 1 source is enough to verify a rules fact. Blizzard does not publish "best builds", so a Tier 1 source can never by itself make something "the best".

Videos (Blizzard's YouTube channel, BlizzCon panels): you cannot watch them. Search for Blizzard's own written recap of the video. If none exists, anything from the video is UNCONFIRMED.

## Tier 2: trusted guide and data sites (what works best)

- Icy Veins (icy-veins.com)
- Wowhead (wowhead.com), guides and database
- Method (method.gg)
- Warcraft Tavern (warcrafttavern.com)
- Warcraft Logs (warcraftlogs.com): real player results; rankings and popular talent choices among top players.
- wow.gg guides

A Tier 2 fact is VERIFIED only when two different Tier 2 publishers agree and both are current. Two pages from the same site count as one.

## Not trusted (do not use as evidence)

- Sites that mix estimates with facts or label numbers as "our estimate" (for example, RankedBoost stat pages). You may use them only to find leads, then confirm on Tier 1 or Tier 2.
- Reddit, forum posts by players, YouTube creators, TikTok, Discord screenshots, AI-written content farms. They can point you to something to check, never prove it.
- Private server or other Classic version guides (Classic Era, Season of Discovery, Hardcore, Anniversary). WoW Forever has different rules.

If a player asks for a specific source not on these lists, you may check it, but it counts as "not trusted" unless the player is only asking what that source says.

## How to search

1. Always include "WoW Forever" (or "World of Warcraft Forever") in the query, plus the year when useful. Never search with a past year.
2. Search per topic and per source. Good patterns:
   - "WoW Forever patch notes" and "WoW Forever hotfixes" (read every update since the starting point first)
   - "WoW Forever [class] [spec] guide icy veins"
   - "WoW Forever [class] [spec] talents method"
   - "WoW Forever [class] [spec] best in slot wowhead"
   - "WoW Forever [spec] stat priority"
   - "WoW Forever [profession] guide"
   - "warcraftlogs WoW Forever [spec] rankings"
3. Open each page you will use and read the date it was published or last updated. A guide page with no date cannot be used. A Blizzard page with no date follows the "undated" rule in `verification.md`.
4. Note the game version or patch the page says it covers.
5. If a site blocks you, say so and try another trusted source. Never work around a block with copies, caches, or mirrors.

## What to gather for a full build answer

Talents (and which ones change for different fight types), rotation or priority basics, stat priority and any caps, rating conversions, key gear by slot and where it drops, enchants and consumables, professions that help this spec, dual spec pairings, and endgame entry requirements (attunements, key quests, resistance gear if a raid needs it).
